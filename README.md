# Honyomi

Mihon 风格的漫画 / 小说 / 视频阅读器（HarmonyOS / ArkTS 移植版），支持在线扩展源（Mihon 插件）与本地源。

## 本地源（固定文件夹）

在「浏览」页选择「本地漫画」「本地小说」「本地视频」即可使用本地源。首次使用时点击「选择文件夹」，从系统文件选择器中选定一个文件夹并授权，之后应用会一直记住该文件夹（重启后自动恢复访问权限）。顶栏「同步」菜单可随时「立即同步」或「更换文件夹」。

由于系统限制，普通应用不能直接遍历用户目录，同步时会把所选文件夹整树复制进应用沙箱再扫描，因此内容约占等量存储空间；从文件夹删除内容后需重新执行同步才会生效。

### 目录组织格式

指定本地文件夹后，应用会自动在其中创建 `comic`、`novel`、`anime` 三个子文件夹（若因权限等原因创建失败，可在文件管理器中手动创建）。三个本地源分别只扫描对应的子文件夹：

```
<所选文件夹>/
├── comic/                          # 「本地漫画」扫描这里
│   └── 漫画A/
│       ├── 第01话/001.jpg ...      # 章节 = 图片目录（jpg/jpeg/png/webp/gif/bmp/avif）
│       ├── 第02话.zip              # 章节 = zip / cbz 压缩包（内含图片）
│       └── 第01卷/第03话/001.jpg   # 支持分层，章节名显示为「第01卷 / 第03话」
├── novel/                          # 「本地小说」扫描这里
│   └── 小说B/
│       ├── 第一章.txt              # 章节 = 一个 txt 文件
│       └── 上卷/第五章.txt         # 支持分层，章节名显示为「上卷 / 第五章」
└── anime/                          # 「本地视频」扫描这里
    └── 剧集C/
        ├── 01.mp4                  # 一集 = 一个视频文件（mp4/mkv/webm/mov/m4v）
        └── 第一季/02.mkv           # 支持分层，章节名显示为「第一季 / 02」
```

说明：

- 子文件夹内每个顶层目录是一部作品；散落在子文件夹根目录的文件不会作为作品显示。
- 压缩包章节（zip / cbz）会在阅读时自动解压。
- 所选文件夹建议专用于本地源：同步会把文件夹整树复制进应用沙箱，放入无关内容会额外占用存储空间。

### 系统选择器操作提示

HarmonyOS 文件选择器的「文件夹」模式只显示目录（文件被隐藏），且需通过右上角「⋮ → 多选」进入多选模式后勾选文件夹，再点击右上角按钮确认返回。
