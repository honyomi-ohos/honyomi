## 一、引言

Honyomi（包名 `fun.shuey.honyomi`）是一款本地优先的漫画 / 小说 / 视频阅读器。
我们高度重视个人信息保护，本政策说明应用如何处理信息，帮助你了解我们收集、
使用、存储和保护个人信息的情况。

本应用自身**不收集、不上传、不共享**任何个人信息：

- 无用户注册 / 登录体系（应用本体）；
- 无内嵌统计、分析或崩溃上报 SDK；
- 无广告 SDK；
- 不向开发者服务器发送任何数据（应用无自有后端服务器）。

应用首次运行时，通过应用市场的隐私协议弹窗向用户展示本政策；用户同意后
方可使用应用。用户可随时在应用内「设置 → 关于 → 隐私政策」重新查看本政策。

以下情形中，应用会按用户主动发起的操作，与第三方网站或服务发生必要的
网络交互，涉及的有限信息详见第二节、第三方服务详见第四节。

## 二、我们如何处理信息

| 场景                        | 是否默认开启        | 涉及信息            | 用途与去向                                         |
|---------------------------|---------------|-----------------|-----------------------------------------------|
| 本地书库 / 阅读进度 / 下载记录 / 偏好设置 | —             | 仅存储于设备本地        | 不上传                                           |
| 打开在线书源（用户自行安装的扩展）浏览、阅读    | 关（安装并启用扩展后生效） | 用户浏览请求直达对应第三方站点 | 由该站点按其自身政策处理，应用不经手、不存储                        |
| 连接追踪服务（同步阅读进度）            | 关（用户主动登录后生效）  | 账号授权令牌、进度数据     | 直达用户选择的追踪服务；令牌仅存于设备安全存储                       |
| 视频弹幕（dandanplay）          | 开（可随时关闭）      | 正在播放的作品标题       | 发送至 api.dandanplay.net 用于匹配剧集并加载弹幕；不发送账号或设备标识 |
| 加密 DNS（DoH）               | 关             | 域名解析请求          | 用户启用后发送至所选 DoH 服务商                            |
| 听书（朗读）                    | —             | 小说文本            | 调用系统端侧语音合成能力，在设备本地完成朗读                        |
| 备份 / 恢复                   | —             | 书库、分类、阅读进度等     | 导出为文件保存于用户选择的位置；**不含**任何令牌、密码或 Cookie         |
| 应用锁                       | 关             | 本地生物识别校验        | 仅用于解锁应用，生物信息不离开设备（由系统校验，应用不采集）                |

应用声明的全部权限见第三节。所有权限均为系统级（normal）授权，应用**未申请**
任何需要用户弹窗授权（user_grant）的敏感权限，不读取通讯录、短信、通话记录、
精确位置、麦克风、相机等信息。

## 三、权限清单

| 权限                                      | 用途                      |
|-----------------------------------------|-------------------------|
| ohos.permission.INTERNET                | 加载在线书源内容、连接用户选择的服务      |
| ohos.permission.GET_NETWORK_INFO        | 获取网络状态以提示联网功能可用性        |
| ohos.permission.FILE_ACCESS_PERSIST     | 记住用户授权导入的本地书库目录（免重复选目录） |
| ohos.permission.ACCESS_BIOMETRIC        | 应用锁的本地生物识别校验            |
| ohos.permission.PRIVACY_WINDOW          | 防截屏隐私保护（用户开启后生效）        |
| ohos.permission.KEEP_BACKGROUND_RUNNING | 下载 / 听书 / BT 下载在后台持续运行  |

## 四、第三方服务说明

应用本身不集成收集个人信息的第三方 SDK。以下第三方服务均在**用户主动操作**
时才会被使用，且各自受其隐私政策约束：

| 服务                                                                   | 触发方式                | 发送内容          | 存储位置                          |
|----------------------------------------------------------------------|---------------------|---------------|-------------------------------|
| 追踪服务（AniList、MyAnimeList、Kitsu、Shikimori、Bangumi、MangaUpdates、Hikka） | 用户主动连接账号            | OAuth 授权、阅读进度 | 访问令牌仅存设备关键资产存储（TEE），不上传至任何其他方 |
| dandanplay 弹幕服务                                                      | 视频播放且弹幕开启（默认开启，可关闭） | 作品标题（用于匹配剧集）  | 弹幕内容仅内存缓存，不落盘                 |
| 在线书源站点（用户安装的扩展所指向的网站）                                                | 用户浏览 / 阅读该书源        | 浏览请求（直达该站点）   | 由该站点自行处理                      |
| DoH 服务商                                                              | 用户开启加密 DNS（默认关闭）    | 域名解析请求        | 不含用户身份信息                      |

扩展（书源插件）以 `.honyomiplug` 包形式由用户主动安装，正式版仅允许通过
HTTPS 分发；应用不预置任何内容源，扩展行为由其各自的服务条款与隐私政策约束。

## 五、数据存储与安全

- 本地数据（书库、进度、设置）存储于应用沙箱，卸载即彻底删除；
- 追踪服务令牌 / 密码、扩展声明的敏感配置项：存入系统**关键资产存储服务
  （Asset Store，硬件安全环境 TEE）**；
- 网络 Cookie：AES-256-GCM 加密存储，密钥保存于关键资产存储；
- 正式发行版启用代码混淆与裁剪；
- 插件网络请求在正式版强制 HTTPS（调试构建放宽仅用于开发）；
- 应用具备应用锁（生物识别）、隐私窗口（防截屏）等用户可选的本地防护能力。

## 六、数据的共享、转让与公开披露

除用户主动发起的上表交互外，我们不会向任何第三方共享、转让或公开披露
任何信息。我们不向开发者或任何服务器上报数据，不出售任何信息。

## 七、你的权利

- **查询 / 导出**：设置内可随时将书库数据备份导出；
- **删除**：卸载应用即删除全部本地数据（含安全存储中的令牌）；
- **撤回授权**：断开追踪服务即在设备上删除对应令牌；关闭弹幕、DoH、
  隐私功能即可停止对应数据发送；禁用 / 卸载扩展即停止与其站点的交互；
- **撤回同意**：卸载应用即视为撤回对本政策的同意。

## 八、未成年人保护

本应用不面向未成年人提供服务。由于在线内容来自用户自行安装的第三方
书源，其中可能包含不适于未成年人的内容；应用默认隐藏标记为 NSFW 的
书源与内容（可在设置中由用户自行开启），建议未成年人在监护人指导下使用。

## 九、政策更新

本政策更新后将在应用内「隐私政策」页与应用市场详情页同步发布。重大变更
将通过应用市场提供的途径提示用户。
