# 更新日志 / Changelog

> 后续版本记录将以 GitHub Releases 形式发布。
> Future release notes will be published as GitHub Releases.

## 1.0.0

- 首个版本：书库、浏览、更新、历史、下载与统计
- 漫画、小说、视频三类书库，内置本地源
- 基于 JSVM 扩展引擎的在线源，支持从插件仓库安装
- 阅读器：分页、双页、条漫、垂直滚动模式
- TTS 朗读、迷你播放条、后台播放与语音快进
- 视频播放器：缓存、手势控制、后台播放
- AVIF 图片解码，EPUB / MOBI 小说解析
- 追踪服务：AniList、MyAnimeList、Bangumi、Kitsu、Shikimori
- 应用锁与生物识别解锁，Cookie 加密与安全偏好
- 备份、分类、桌面卡片与引导页

### English

- Initial release: library, browse, updates, history, downloads and stats
- Manga, novel and video libraries with built-in local sources
- Online sources via the JSVM extension engine, installable from plugin repositories
- Readers with paged, double-page, webtoon and vertical-scroll modes
- TTS reading with mini bar, background playback and voice seek
- Video player with caching, gesture controls and background playback
- AVIF image decoding and EPUB / MOBI novel parsing
- Trackers: AniList, MyAnimeList, Bangumi, Kitsu and Shikimori
- App lock with biometric unlock, encrypted cookies and secure preferences
- Backups, categories, home-screen widgets and onboarding
